------------------------------------------------------------
1) What is FastAPI?
------------------------------------------------------------
FastAPI is a modern, high-performance Python framework used to build APIs.

What it does:
- You write API endpoints (routes).
- Clients send HTTP requests (GET/POST/etc.).
- FastAPI returns HTTP responses.

Built with:
- Starlette → handles web/HTTP layer
- Pydantic → validates request/response data

Key features:
- Async support (good for many concurrent requests)
- Automatic request data validation
- Automatic API docs (Swagger UI at /docs)
- Uses Python type hints to make code safer and cleaner

------------------------------------------------------------
2) Need of FastAPI?
------------------------------------------------------------
Most applications use a frontend + backend setup.

Example architecture:
- Frontend: React / Angular / Mobile app
- Backend: FastAPI API server
- Database: PostgreSQL / MySQL / MongoDB / etc.

Workflow:
1. Frontend calls the FastAPI server.
2. FastAPI validates input data.
3. FastAPI performs business logic (DB operations, calculations, etc.).
4. FastAPI returns the response.

Why people choose FastAPI:
- Fast performance
- Less boilerplate code
- Built-in validation + good error messages
- Auto-generated documentation

------------------------------------------------------------
3) What is Monolithic Architecture?
------------------------------------------------------------
Monolithic architecture means the entire application is built as one single unit.

In a monolith, many parts live inside the same application, for example:
- Authentication
- Orders
- Payments
- Admin panel
- Database logic
- API routes

Example (E-commerce):
- Login system
- Product system
- Cart system
- Payment system
- Order system
- Admin system

5) How to start FastAPI?
------------------------------------------------------------
Minimum steps:
1. Create a FastAPI app
2. Create routes (endpoints)
3. Run with uvicorn

Example: main.py

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"message": "Hello from FastAPI"}
```

Run:
1) cd to your project folder
2) uvicorn main:app --reload

Docs:
- Open http://127.0.0.1:8000/docs

6) About HTTP Methods
------------------------------------------------------------
HTTP methods describe what kind of action a client wants to perform on a resource.

Common methods in REST APIs:
- GET → read/fetch data
- POST → create new data
- PUT/PATCH → update data
- DELETE → remove data

------------------------------------------------------------
7) Path Parameters vs Query Parameters
------------------------------------------------------------
A) Path Parameters
- Used in the URL path to identify a specific resource.

Example:
- /patients/{patient_id}

Example call:
- http://localhost:8000/patients/P002

In FastAPI:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/patients/{patient_id}")
def get_patient(patient_id: str):
    return {"patient_id": patient_id}
```

B) Query Parameters
- Optional values in the URL after ?
- Used for filtering/sorting/pagination.

Example:
- /patients?age=20&sort=asc

Example call:
- http://localhost:8000/sort/sort_by?height&order=asc

------------------------------------------------------------
8) What is an HTTP Status Code?
------------------------------------------------------------
HTTP status codes are numbers returned by the server to indicate the result of a request.

Common status codes:
- 200 OK → request successful
- 201 Created → resource created
- 204 No Content → success, but no response body
- 301 Moved Permanently → moved to a new URL
- 400 Bad Request → invalid request (client error)
- 401 Unauthorized → authentication missing/failed
- 404 Not Found → resource not found
- 500 Internal Server Error → server error

9) What is Pydantic and why is it used?
------------------------------------------------------------
FastAPI uses Pydantic for data validation and parsing.

Why it’s needed:
- Python is dynamically typed, so input can be wrong type/format.
- Pydantic validates incoming data automatically.
- It also helps generate clean API schemas.

Basic import:
```python
from pydantic import BaseModel
```

------------------------------------------------------------
10) Pydantic: Type hints + Model example
------------------------------------------------------------
Example request model:

```python
from pydantic import BaseModel, EmailStr, Field

class User(BaseModel):
    name: str
    email: EmailStr
    age: int = Field(gt=0, lt=130)  # must be between 1 and 129
```

Use in FastAPI:
```python
from fastapi import FastAPI

app = FastAPI()

@app.post("/users")
def create_user(user: User):
    return user
```

Now FastAPI will:
- Parse JSON → Python types
- Validate constraints (email format, age range, etc.)
- Return clear 422 errors if validation fails

11) Common Pydantic validation features
------------------------------------------------------------
1) Email validation
```python
from pydantic import EmailStr

email: EmailStr
```

2) URL validation
```python
from pydantic import AnyUrl

website: AnyUrl
```

3) Field constraints using Field
```python
from pydantic import Field

age: int = Field(gt=10)  # age must be > 10
```

4) Annotated (add metadata/constraints)
```python
from typing import Annotated
from pydantic import Field

Age = Annotated[int, Field(gt=18, le=60, title="Age")]
```

------------------------------------------------------------
12) Field validators (extra validation logic)
------------------------------------------------------------
If you need custom logic, you can use field validators.

Example:
```python
from pydantic import BaseModel, field_validator

class Item(BaseModel):
    price: float

    @field_validator("price")
    @classmethod
    def validate_price(cls, v: float):
        if v < 0:
            raise ValueError("price must be >= 0")
        return v
```
